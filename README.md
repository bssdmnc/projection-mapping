# 🎬 Projection Mapping Studio (Веб-видеомаппинг для проектора)

Легковесный, производительный инструмент для проекционного видеомаппинга в браузере (WebGL). Работает без установки тяжелых программ (вроде MadMapper или Resolume) прямо на вашем компьютере или проекторе.

---

## 🌟 Возможности

1. **Произвольная 4-точечная деформация (Quad Corner Pinning)**:
   - Подгонка углов под любые физические объекты: стены, коробки, кубы, экраны под углом, картины.
   - Сетка субдискретизации $20 \times 20$ в WebGL — плавное искажение без изломов и артефактов на 60 FPS.
   - Перетаскивание углов мышью или тачем.
   - **Ювелирная калибровка**: выбор угла клавишами `1`, `2`, `3`, `4` или `Tab` и микро-подгонка **Стрелками** с точностью до 1 пикселя (`Shift+Стрелки` для шага в 10px).

2. **Несколько независимых поверхностей (Multi-surface)**:
   - Добавляйте сколько угодно поверхностей (например, грань коробки 1, грань коробки 2, стена на фоне).
   - Индивидуальная настройка яркости, контрастности, прозрачности и режима наложения (Normal, Add, Screen).
   - Включение/отключение отображения любой поверхности в один клик.

3. **Встроенные генераторы калибровочных и визуальных паттернов**:
   - 🎯 **Сетка калибровки (Crosshairs & Grid)**: с разметкой углов, концентрическими кругами и шкалой для идеального выравнивания.
   - 🌌 **Киберпанк 3D Неоновый Тоннель**: динамическая анимированная перспектива.
   - 💻 **Матрица (Digital Rain)**: классический падающий цифровой дождь.
   - 🌈 **Радужная Плазма**: переливающиеся световые волны.
   - ⏱️ **Неоновые Цифровые Часы**: стильные часы с датой для инсталляций.
   - ⚪🔴🟢🔵⚫ **Сплошные цвета**: белый, красный, зеленый, синий, черный для калибровки цветопередачи проектора.

4. **Любой свой контент**:
   - Загрузка локальных **видео** (`.mp4`, `.webm`) и **изображений** (`.png`, `.jpg`).
   - 📷 Захват **веб-камеры** в реальном времени.
   - 🖥️ Захват **экрана / окна** (Screen Share): транслируйте любое видео с YouTube, браузер, игру или окно программы прямо внутрь проекционной поверхности.

5. **Режим двух экранов (Dual Monitor / Projector Mode)**:
   - Кнопка **«📽️ Окно проектора»** открывает отдельное окно (`display.html`).
   - Перетащите его на проектор и нажмите `F11`.
   - Вся калибровка в основном окне **мгновенно синхронизируется** по воздуху без отображения элементов управления и курсора на стене!

6. **Сохранение калибровок**:
   - Автоматическое сохранение в `localStorage` браузера.
   - Экспорт в `.json` файл и импорт пресетов.

## 🚀 Быстрый запуск

### Вариант 1 (Windows, двойной клик):
Запустите файл `start.bat`. Он поднимет локальный сервер и сам откроет браузер.

### Вариант 2 (Командная строка):
```bash
cd code/projection-mapping
node server.js
```
Откройте в браузере: **`http://localhost:3050`**  
*(Если проектор подключен к тому же Wi-Fi, на нем можно открыть адрес `http://<IP-вашего-ПК>:3050`)*

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| **H** | Скрыть / показать все меню и управляющие маркеры |
| **F** | Включить / выключить полноэкранный режим |
| **Tab** | Переключить активный угол по кругу |
| **1, 2, 3, 4** | Выбрать угол: 1=TL, 2=TR, 3=BR, 4=BL |
| **Стрелки** | Сдвинуть выбранный угол на **1px** |
| **Shift + Стрелки** | Сдвинуть выбранный угол на **10px** |
| **[** / **]** | Переключиться между поверхностями |
